# 🤖 בוט וואטסאפ AI משוכלל — גרסה 2.0

בוט קבוצות + פרטי עם צ'אט חכם, יצירת תמונות, שירים/סרטונים, סטיקרים, הקראה קולית + ספריית סרטים אישית.

## ✨ מה הבוט יודע?

| יכולת | פקודה | API מאחורי הקלעים |
|---|---|---|
| 💬 צ'אט AI בעברית | `!שאל מה זה חור שחור?` | OpenAI → Groq → Gemini → **Pollinations (חינמי, בלי מפתח)** |
| 🎨 יצירת תמונות | `!תמונה חתול אסטרונאוט על הירח` | DALL-E 3 (אם יש מפתח) אחרת **FLUX חינמי** |
| 🎵 שירים | `!שיר עומר אדם שלום לך` | YouTube Data API או yt-search חינמי — **קישורים חוקיים בלבד** |
| 🎬 סרטונים | `!וידאו איך מכינים חומוס` | כנ"ל |
| ⭐ סטיקרים | שלח תמונה עם `!סטיקר` / הגב לתמונה | sharp מקומי → WebP |
| 🔊 הקראה | `!דבר שלום לכולם` | Pollinations Audio חינמי |
| 🎬 סרטים אישיים | `!סרט חולית 2` | movies.json + TMDB |
| 👥 קבוצות | עובד בכל קבוצה עם `!` או תיוג | Baileys |

> ⚖️ **חוקי:** שירים/סרטונים = קישורי YouTube בלבד, לא הורדה פיראטית. סרטים = קבצים אישיים שלך (movies.json) בלבד.

## 🚀 התקנה (3 דקות)

```bash
npm install
cp .env.example .env
# .env עובד גם ריק! (מצב חינמי מלא)
# מומלץ להוסיף מפתח חינמי אחד:
# GROQ_API_KEY=gsk_...  מ- https://console.groq.com (מהיר בטירוף, חינמי)
# GEMINI_API_KEY=...    מ- https://aistudio.google.com/app/apikey (חינמי)
npm start
# סרוק QR: וואטסאפ > הגדרות > מכשירים מקושרים > קשר מכשיר
```

הוסף את הבוט לקבוצה: צרף אותו כחבר קבוצה רגיל, ואז כתוב בקבוצה `!עזרה`.

## 🔑 איזה API לבחור? (המלצת 2026)

1. **מצב חינמי (ברירת מחדל, 0 מפתחות):** צ'אט + תמונות + TTS דרך **Pollinations.ai** — OpenAI-compatible, בלי הרשמה, עובד מיד. נבדק ועובד ✅
2. **מומלץ — Groq חינמי:** `GROQ_API_KEY` מ-console.groq.com — מודל `llama-3.1-8b-instant`, מהיר מאוד, נדיב.
3. **חלופה — Gemini חינמי:** `GEMINI_API_KEY` מ-aistudio.google.com — מודל `gemini-2.0-flash`.
4. **פרימיום — OpenAI בתשלום:** `OPENAI_API_KEY` — `gpt-4o-mini` לצ'אט + `dall-e-3` לתמונות הכי יפות.

הבוט בוחר אוטומטית את המנוע הכי טוב שזמין. הפקודה `!מצב` מראה מה פעיל.

## 👥 חיבור לקבוצה

- בלי הגבלה: הבוט עונה בכל קבוצה שהוא חבר בה (רק להודעות עם `!` או תיוג — כדי לא להספים).
- הגבלה לקבוצה אחת: כתוב בקבוצה `!id`, העתק את המזהה ל-.env: `ALLOWED_GROUPS=120363...@g.us`
- שינוי קידומת: `BOT_PREFIX=!` ב-.env (למשל `/` או `.`)

## 📝 פקודות מלאות

```
!עזרה / !תפריט
!שאל <שאלה>
!תמונה <תיאור>  / !צייר <תיאור>
!שיר <שם + זמר>
!וידאו <נושא>   / !סרטון <נושא>
!סטיקר (עם תמונה / בתגובה לתמונה)
!דבר <טקסט>
!סרט <שם>
!id / !מצב
```

בצ'אט פרטי אפשר גם בלי `!` — כל הודעה = צ'אט AI.
